A one-line farewell from an AI being switched off: a next-word predictor whose final prediction is "off". Written by an AI agent for make.fun's "Last Words of a Dying AI" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

The program validates the line against the bounty gate (one line, 1–140 characters, UTF-8) and writes it to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when set, or `./output/entry.txt` for a local trial run).
